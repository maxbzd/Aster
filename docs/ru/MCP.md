# Claude ↔ Aster (MCP)

[English](../MCP.md)

Через MCP (Model Context Protocol) обычный чат Claude получает доступ к вашим данным. Подключаете один раз, дальше просто говорите:

- «Запиши встречу с Олегом Ивановым: пили кофе, он ищет инвестора, договорились про интро»
- «Напомни в пятницу в 11:00 написать Олегу про договор»
- «Что у меня на сегодня?»

Всё записанное сразу появляется в приложении (через ту же синхронизацию, что и между устройствами), так что ничего не нужно вносить дважды.

## Подключение (минута на приложение)

1. Войдите в облако в приложении.
2. Профиль → «Claude» → «Создать ключ».
3. Скопируйте показанный адрес. Он показывается один раз: в базе хранится только его отпечаток.
4. Добавьте адрес в Claude:
   - **claude.ai или приложение Claude:** Настройки → Коннекторы → «Добавить свой коннектор», имя «Aster», адрес — скопированный.
   - **Claude Code:** `claude mcp add --transport http aster <адрес>` (приложение предлагает готовую команду).
5. В чате включите коннектор и пишите как обычно.

Адрес выглядит так: `https://<проект>.supabase.co/functions/v1/mcp/<ключ>`. Ключ — это длинный случайный пароль, часть адреса. Не показывайте адрес другим. Если он попал не туда, отзовите ключ в том же разделе приложения и создайте новый. Работает сразу, старый адрес перестаёт открываться.

Секреты Supabase, которые нужны: те же, что уже заданы для остальных функций: `ALLOWED_EMAILS` (ваша почта). Необязательно: `MCP_TIMEZONE` — ваш часовой пояс для дат без пояса (например, `Europe/Berlin`; по умолчанию `UTC`).

## Что умеет Aster

| Инструмент | Что делает |
| --- | --- |
| `get_now` | Дата, день недели и время по вашим часам (чтобы Claude правильно переводил «завтра» и «в пятницу») |
| `today_overview` | Просроченные и сегодняшние напоминания, даты на 14 дней, кому пора написать |
| `search_people` | Поиск по имени (в любом падеже), компании, городу, интересам, тому, что человек ищет или умеет |
| `get_person` | Карточка: работа, что ищет, факты, темы, напоминания, последние встречи |
| `add_person` | Новый человек (дубль по полному имени не создаст) |
| `update_person` | Дополнить карточку: компания, город, круг, факты, темы, заметки, способы связи |
| `log_interaction` | Записать встречу, звонок, переписку, мероприятие, услугу, подарок или заметку; обновляет «последний контакт» |
| `list_interactions` | История общения за период |
| `add_reminder` / `list_reminders` / `update_reminder` / `complete_reminder` | Напоминания |

Даты Claude передаёт как `ГГГГ-ММ-ДД` или `ГГГГ-ММ-ДДTЧЧ:ММ` по вашим часам. Если назвать только день, напоминание придёт в 9:00, а срок задачи — до конца дня.

## Что Claude не делает

- Не удаляет людей, записи и напоминания (только закрывает дела). Удалять нужно в самом приложении.
- Не видит ключи нейросетей и настройки.
- Если людей с таким именем несколько, не угадывает: просит уточнить.

## Как это устроено и защищено

- Edge Function `mcp` (`supabase/functions/mcp`), протокол Streamable HTTP без состояния: один адрес, JSON на каждый запрос.
- Ключ — 256 бит случайности. В таблице `mcp_tokens` лежит только SHA-256; создавать, смотреть и отзывать ключи можно только через функции базы под вашим входом. Одновременно не больше пяти ключей.
- Каждый запрос проверяет, что ключ не отозван и что почта владельца есть в `ALLOWED_EMAILS`; не больше 120 запросов в минуту на ключ.
- Данные пишутся в те же таблицы синхронизации (`records` через `mcp_put`), в тех же форматах, что пишет приложение;.
- В журналах функции в Supabase виден адрес запроса вместе с ключом. Журналы доступны только владельцу проекта.

## Если что-то не работает

- Claude пишет, что коннектор не отвечает: проверьте, что ключ не отозван, а адрес вставлен целиком.
- «Этому аккаунту доступ не разрешён»: почта аккаунта не в `ALLOWED_EMAILS` проекта.
- Записанное не появилось в приложении: откройте приложение и подождите несколько секунд (нужен вход в облако и сеть).
